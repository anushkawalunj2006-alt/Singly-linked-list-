
Smart Campus Lost & Found Management System

•Project Overview:

The Smart Campus Lost & Found Management System is a menu-driven
C++ application developed using the Singly Linked List data structure.

The system helps manage lost and found items within a college campus.

•Problem Statement:

Develop a menu-driven C++ application for managing lost and found
items in a college campus using a Singly Linked List. The system
allows users to add, display, search, update and delete item records.

•Objectives:

- To implement Singly Linked List in a real-world application.
- To perform insertion, deletion and searching operations.
- To dynamically manage item records.
- To demonstrate the practical use of pointers.
- To manage a variable number of records efficiently.

•Data Structure Used:

Singly Linked List

Each item is stored as a node containing:

- Item ID
- Item Name
- Category
- Location
- Status
- Pointer to the next node

•Features:

1. Add Item
2. Display All Items
3. Search Item
4. Update Item
5. Delete Item
6. Exit

•Technologies Used:

- C++
- Data Structures
- Singly Linked List
- Pointers
- Dynamic Memory Allocation

•Operations:

1.Insertion:
A new item is added as a node to the linked list.

2.Traversal:
All item records are displayed by traversing the linked list.

3.Searching:
An item can be searched using its Item ID.

4.Updating:
Location and status of an existing item can be updated.

5.Deletion:
An item can be removed from the linked list.

•Conclusion:

The project demonstrates the practical application of a Singly
Linked List for managing dynamic records in a college Lost and
Found system.
